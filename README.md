## What I'm working on

- 📚 **RAG for my homelab assistant:** building a knowledge base on TrueNAS for the assistant to pull from.
- 🔧 **3D model → welding cut sheets:** an app that takes a 3D model and generates cut sheets for welding projects.
- 🎮 **A small mock game in Godot:** a showcase for the 3D models I'm making and animating with automation tools.
- 🎧 **Music production and audio:** studying audio engineering at Recording Arts Canada and building a portfolio. I'm open to freelance work.

## The lab
- **Omarchy - intel i7 4790k (main Linux box):** my sandbox and dev environment. Runs Ollama on an RTX 3060, plus Hermes, Paperclip and Claude Code.
- **Proxmox host (HP Prodesk Mini 600 G4):** a Docker-host LXC for Homepage, Open WebUI and Jellyfin, plus a Conan Exiles Enhanced private server.
- **TrueNAS (custom build with intel i7 4790k):** central storage and the future home of the assistant's knowledge base. Right now it's mostly a big unsorted pile, and the Inbox → Sort workflow is how I plan to fix that.
- **Omarchy mini (Lenovo ThinkCentre):** remote hub and Valheim server.
- **MSI Katana 17B13V laptop (Windows 11):** main machine for audio and dev work. Windows only to maintain audio programs with strict licensing. 
- **Recovery tooling:** a systemd-based orchestrator on the Proxmox side that restarts services with safety gates. The AI agent gets a locked-down SSH account limited to read-only and per-service restart actions.
